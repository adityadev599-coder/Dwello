# Dwello – Urban Living Assistant

Dwello is a frontend web application developed as a **university mini project**.

The purpose of this project is to help people who are shifting to a new city by providing **rental homes, appliances, and local services** on a single platform.

---

## Objective of the Project

The main objectives of this project are:

- To help users find flats, PGs, and rooms easily
- To provide rental appliances such as refrigerators, ACs, and washing machines
- To connect users with local services like cooks, maids, and cleaners
- To make bill sharing simple for people living together
- To provide a simple and user-friendly platform for urban living needs

---

## Technologies Used

The project is developed using:

- **HTML** – For creating the structure of the web pages
- **Tailwind CSS** – For styling and responsive design
- **JavaScript** – For adding interactivity and dynamic functionality

> This project is completely **frontend-based** and does not use any backend or database.

---

## Features of the Project

### 🏠 Home & Property Search
- Search for flats, PGs, and rooms
- Property listing section
- Display of property details such as rent, location, bedrooms, and bathrooms

### 📦 Rental Appliances
Users can explore rental options for essential household appliances such as:

- Refrigerator
- Air Conditioner
- Washing Machine
- Other household appliances

### 🛠️ Local Services
The platform provides access to local services such as:

- Cooks
- Maids
- Cleaning services
- Repair services
- Wi-Fi services

### 💰 Bill Split
The bill-splitting section helps people living together divide common expenses such as:

- Rent
- Tiffin
- Wi-Fi
- Maid's salary

### 📱 Responsive Design
The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

### 📞 Contact Section
Users can find contact information and reach out for support or queries.

## How to Run the Project

### Method 1 – Open Directly

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

### Method 2 – Using VS Code Live Server

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your default browser.

## Scope of the Project

This project demonstrates the practical use of frontend web development technologies to solve a real-life problem.

The project helps in understanding:

- HTML page structure
- CSS styling and responsive layouts
- Tailwind CSS utility classes
- JavaScript-based interactivity
- Website navigation
- User-friendly interface design
- Responsive web development

The project can be extended in the future by adding a **backend, database, authentication, online payments, and real-time property/service management**.

---

## Limitations

Since Dwello is a frontend-only project:

- There is no backend server.
- There is no database.
- Property data is static.
- Search functionality is limited to the frontend interface.
- User authentication is not implemented.
- Online booking and payments are not implemented.

## Conclusion

Dwello is a simple and effective **university mini project** that demonstrates the use of **HTML, Tailwind CSS, and JavaScript** to build a real-world web application.

The project focuses on making the process of shifting to a new city easier by bringing **homes, rental appliances, local services, and bill sharing** together on a single platform.
